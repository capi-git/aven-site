How it works

From prompt to reviewed change.

Aven doesn't replace your agent. It gives it a place to work where you can see everything it does.

  1. 01

    Sign in to your agent

    Install Claude Code, Codex or another supported CLI and sign in with your own account.

  2. 02

    Open a project

    Choose a folder. Conversations, files and Git stay together in its workspace.

  3. 03

    Ask and watch

    The agent edits and runs commands in the access mode you choose, with the browser beside the chat.

  4. 04

    Review and commit

    Check the diff, point at anything on the page that needs work, then commit when you're happy.

Good questions

Before you download.

Is Aven free?

Yes. Aven is free and MIT licensed. It doesn't include model access or sell tokens, so your subscription or API usage stays with your provider.

Which agents does it work with?

Claude Code, Codex, Cursor, Grok Build, OpenCode, Pi, omp and fx. What's available depends on the tool you have installed and its version.

Which Macs are supported?

Apple Silicon Macs running macOS 13 or later. Intel Mac builds aren't provided yet.

Why does macOS block it the first time?

Aven isn’t notarized by Apple yet. Unzip the download and move Aven to Applications. If macOS blocks it the first time, open System Settings → Privacy & Security, scroll down and choose Open Anyway. After that, Aven updates itself.

How do updates work?

Aven downloads signed updates in the background and shows Restart to update. You choose when; it never interrupts a running agent.

Can the agent change my files?

Yes, within the access mode you pick for each task. Check it before you start, and use Git for projects you let agents change.

Is there a Windows version?

A Windows test build is on the releases page. A regular Windows release is coming.
